# Project 09 - Country Information Finder

A simple Python project that fetches information about a country using a REST API.

## Features

- Takes country name as input
- Displays country name
- Displays capital city
- Displays region
- Displays population
- Displays currency
- Displays languages
- Handles invalid country names and API errors

## API Used

REST Countries API

## Technology Used

- Python
- Requests Library
- REST API
- JSON
- Google Colab
