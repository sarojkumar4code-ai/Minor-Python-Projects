# Project 10 - Random Cat Fact Generator

A simple Python project that fetches and displays a random cat fact using an online API.

## Features

- Connects to a public API
- Fetches a random cat fact
- Displays the fact to the user
- Handles API connection errors
- Generates a different fact on each request

## API Used

Cat Fact API

## Technology Used

- Python
- Requests Library
- REST API
- JSON
- Google Colab
