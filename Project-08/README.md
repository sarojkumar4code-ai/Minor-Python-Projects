# Project 08 - Random Joke Generator

A simple Python project that fetches and displays random jokes using an online API.

## Features

- Fetches a random joke using an API
- Displays the joke setup
- Displays the punchline separately
- Handles API request errors
- Uses JSON data from the API

## API Used

Official Joke API

## Technology Used

- Python
- Requests Library
- REST API
- JSON
- Google Colab
