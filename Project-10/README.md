# Project 10 - Random Dog Image Generator

A simple Python project that fetches and displays a random dog image using an online API.

## Features

- Connects to a public API
- Fetches a random dog image
- Displays the image directly in Google Colab
- Handles API connection errors
- Generates a different image on each request

## API Used

Dog CEO API

## Technology Used

- Python
- Requests Library
- REST API
- JSON
- Google Colab
