# Project 06 - Currency Converter

A simple Python project that converts one currency into another using a real-time exchange rate API.

## Features

- Takes amount as input
- Takes source currency
- Takes target currency
- Fetches exchange rates using an API
- Calculates the converted amount
- Displays the conversion result

## API Used

Frankfurter Exchange Rates API

## Technology Used

- Python
- Requests Library
- REST API
- Google Colab
