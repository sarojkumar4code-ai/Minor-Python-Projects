# Project 07 - Weather Report

A simple Python project that fetches current weather information using a weather API.

## Features

- Takes city name as input
- Finds city coordinates using an API
- Fetches current weather information
- Displays temperature
- Displays humidity
- Displays wind speed
- Handles invalid city and API errors

## API Used

Open-Meteo Weather API
Open-Meteo Geocoding API

## Technology Used

- Python
- Requests Library
- REST API
- JSON
- Google Colab
